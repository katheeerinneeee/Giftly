# Giftly — сайт персоналізованих подарункових боксів

**Автор:** Катерина Деласа · **Навчальний проєкт, 2026**  
**Місто реалізації:** Київ, Україна

Сайт створено за навчальною послідовністю: опис бізнесу → генерація HTML/CSS/JS → перевірка у Visual Studio Code → завантаження на GitHub → GitHub Pages.

## Структура файлів

```text
Giftly_GitHub_Ready/
├── index.html       # Головна сторінка
├── styles.css       # Дизайн та мобільна адаптація
├── app.js           # Каталог, кошик, мови, анкета
├── server/
│   └── index.js     # Окремий серверний прототип для WayForPay
├── package.json     # Залежності сервера
├── .env.example     # Зразок налаштувань без секретів
├── .gitignore       # Захист секретних файлів
└── README.md        # Інструкція
```

## Публікація на GitHub Pages — як у відео викладача

1. Розпакуйте ZIP. Відкрийте папку `Giftly_GitHub_Ready` у **Visual Studio Code**.
2. Для перевірки відкрийте `index.html` у браузері або через розширення **Live Server**.
3. На **github.com** створіть публічний репозиторій, наприклад `giftly-website`.
4. Натисніть **Add file → Upload files** і завантажте **вміст** папки, щоб `index.html` був у корені репозиторію.
5. Збережіть зміни (**Commit changes**).
6. Відкрийте **Settings → Pages → Build and deployment**.
7. У **Source** виберіть **Deploy from a branch**, у **Branch** — `main`, папка `/ (root)`, натисніть **Save**.
8. Дочекайтеся публікації. Зазвичай адреса матиме вигляд `https://ВАШ-ЛОГІН.github.io/giftly-website/`.

**Важливо:** GitHub Pages публікує лише HTML/CSS/JS. Це **демонстраційна версія**: кошик і анкета працюють у браузері, але замовлення не передаються менеджеру, а реальна оплата не працює.

## Функціональність

- Українська й англійська мови.
- Три формати подарунків з бізнес-плану: Giftly S — 999 грн, M — 1599 грн, L — 2499 грн.
- Кошик із підрахунком суми та збереженням у браузері.
- Анкета персоналізації, що зберігає дані **лише локально у браузері**.
- Адаптивний дизайн у пастельних кольорах.
- Авторство та контакти у футері.

## Підготовка до реальних продажів

Для приймання платежів потрібні зареєстрований мерчант WayForPay, HTTPS-домен, окремий Node.js хостинг, захищені змінні середовища, перевірені callback-повідомлення, база замовлень, обробка персональних даних і тестування платіжного сценарію. **Поточний сервер — прототип, не перевірений для комерційного запуску.**

Локальний запуск серверного прототипу:

```bash
npm install
cp .env.example .env
npm start
```

Відкрийте `http://localhost:3000`. Не додавайте `.env` у GitHub і не публікуйте ключ WayForPay.

## Що замінити перед комерційним запуском

- Демонстраційні відгуки на справжні (або видалити блок).

- Додати фактичні реквізити продавця, політику конфіденційності, умови замовлення, доставки, оплати й повернення.
- Вказати справжні соціальні мережі, якщо вони вже існують.
